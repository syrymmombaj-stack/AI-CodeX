# AI CodeX

**AI CodeX** is an AI-first coding workspace designed to help people turn natural-language ideas into clean, editable code.

## Vision
Describe what you want to build, choose a language, generate code, inspect it, improve it, and preview web projects in one focused workspace.

## Current MVP
- Modern responsive coding workspace
- Language selector for HTML/CSS/JS, Python, JavaScript, TypeScript, React, Java, C++ and SQL
- Code editor with copy action
- Live HTML preview
- Prompt shortcuts for building, explaining and improving code
- Dark/light interface
- No exposed API keys

## Next phase
The current version is a frontend MVP. The production AI layer should use a secure backend endpoint so provider API keys are never shipped to the browser. Planned capabilities include real AI generation, streaming responses, project/file context, code explanation, refactoring, debugging and persistent projects.
